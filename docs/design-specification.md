# 视觉设计规范 - Figma设计稿说明

## 设计概述

### 设计目标
- 现代化、简洁的登录注册界面
- 增强品牌识别度和视觉冲击力
- 提供流畅的用户交互体验
- 确保跨设备一致性

### 设计原则
1. **简洁性**: 去除冗余元素，突出核心功能
2. **一致性**: 保持视觉元素和交互模式的一致性
3. **可访问性**: 确保所有用户都能轻松使用
4. **响应性**: 适配各种屏幕尺寸和设备

## 组件规范

### 按钮 (Button)
```
高度: 44px (移动端触摸目标)
圆角: 8px
内边距: 12px 24px
字体大小: 16px
字重: 500

状态样式:
- 默认: 渐变背景，白色文字
- 悬停: 背景加深，轻微阴影
- 按下: 背景更深，无阴影
- 禁用: 灰色背景，降低透明度
```

### 输入框 (Input)
```
高度: 44px (移动端触摸目标)
圆角: 8px

内边距: 12px 16px 12px 48px (左侧图标空间)

## 动画效果

### 过渡动画
```
默认时长: 0.3s
easing: ease-out

悬停效果:
- 缩放: scale(1.02)
- 阴影: 增加阴影深度
- 透明度: 轻微变化

点击效果:
- 缩放: scale(0.98)
- 透明度: 降低10%
```

### 粒子动画
```
粒子数量: 50个
粒子大小: 1-4px
移动速度: 0.5px/frame
连接距离: 100px
颜色: 随机柔和色彩
透明度: 0.1-0.6
```

动画时长: 0.5s

```
